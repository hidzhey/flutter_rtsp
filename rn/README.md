# Archer Link RN

Спроба перенести `flutter_rtsp` на React Native. Поки це етап 1: на екрані сам
стрім і більше нічого, щоб перевірити чи він стабільно тримається на приладі.

## Запуск

```bash
npm install
npx expo prebuild --clean          # генерує android/ та ios/
npm run android                    # expo run:android, потрібен Android SDK
npm run ios                        # expo run:ios, потрібен macOS і Xcode
```

Звичайний Expo Go не підійде: плеєр це нативний модуль, тож треба dev client
або повноцінний білд.

Телефон має бути в Wi-Fi приладу. Підмережа і вирішує, з ким говоримо, таблиця
лежить у `constant/stream.ts` і повторює `getStreamConfig()` з флаттер-апки.

## Що з чого складається

| Файл | Що робить |
|---|---|
| `constant/stream.ts` | Таблиця приладів по підмережах, таймаути, mpv-опції низької затримки |
| `core/streamSession.ts` | Сінглтон, що веде один стрім: TCP-команда, очікування ack, дедлайн спроби, сторож підвисання, перезапуск |
| `core/useNetworkState.ts` | IP телефона на конфіг приладу |
| `store/useStreamStore.ts` | Стан для екрана |
| `app/index.tsx` | Сам екран: `ExpoMpvView` на весь екран, без жодного інтерфейсу |

## Чому expo-mpv

Під `media_kit` у флаттер-апці лежить libmpv, і вся низька затримка тримається
на наборі mpv-властивостей (`cache=no`, `profile=low-latency`, `untimed`,
`demuxer-lavf-o` з `rtsp_transport=tcp` і `fflags=nobuffer`, `framedrop=vo`).
`expo-mpv` це теж libmpv і дає `setPropertyString`, тож ці властивості
переносяться дослівно, разом з поведінкою. Ніякий інший RN-плеєр цього не дає:
`react-native-video` вміє RTSP тільки на Android, а під VLC доведеться підбирати
свої еквіваленти наосліп.

Плеєр захований за `IPlayerHandle` у `core/streamSession.ts`. Якщо expo-mpv
підведе, підміна на VLC це один файл.

## Відкриті питання

- `expo-mpv` вимагає **iOS 16.4**, а флаттер-апка зараз на 15.0 і BC2 на 15.5.
  Якщо 15.x треба тримати, це або форк модуля, або VLC.
- `expo-mpv` молодий і в нього один автор. Для продакшена варто мати запасний
  варіант, тому плеєр і за інтерфейсом.
- Expo SDK тут 57, а в BC2 54. Апки окремі, тож не заважає, але якщо колись
  зливати в одну, доведеться підтягувати.
- Не зібрано і не запущено: на машині, де це писалось, нема Android SDK.
  Перевірені тільки типи, лінт і генерація нативного проєкту.
